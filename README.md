# Quizshow Multiplayer

## Funktionen
- Räume mit Spielcode und Live-Buzzer
- Gastgeber ist Spielleitung und wird nicht als Spieler/Punkteempfänger geführt
- Bei „Falsch“ werden der antwortenden Person nur die Hälfte der Fragepunkte abgezogen (aufgerundet) und der Buzzer automatisch erneut geöffnet
- „Wegmachen – zurück zur Übersicht“ beendet die Frage und kehrt zum Spielbrett zurück
- 60-Sekunden-Timer pro geöffneter Frage
- Frageneditor: Kategorien, Fragen, Lösungen und Punkte pro Frage bearbeiten
- Gastgeber kann Punktestände direkt in der Rangliste anklicken und ändern

## Start
`npm install`
`npm start`

Die Räume sind im Arbeitsspeicher und werden bei einem Server-Neustart zurückgesetzt.
